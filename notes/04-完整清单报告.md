## 一、项目架构总览

**这是一个基于 C++17 的 AI 大模型接入 SDK（ChatSDK），封装了对 DeepSeek、ChatGPT、Gemini 三大云端大模型和 Ollama 本地模型的统一访问接口，上层构建了一个带 Web 前端的 HTTP 聊天服务器（ChatServer），支持多轮会话管理、流式响应、SQLite 持久化存储。**

项目整体架构为三层：
- **底层 SDK** (`sdk/`): 静态库 `libai_chat_sdk.a`，提供模型接入、会话管理、数据持久化能力
- **中间层 ChatServer** (`ChatServer/`): 基于 httplib 的 HTTP 服务器，暴露 RESTful API
- **前端层** (`build/www/`): HTML/CSS/JS 单页应用，支持 Markdown 渲染、代码高亮、SSE 流式展示

## 二、SDK 设计详解

### 2.1 类继承关系图

```
                    Config (基类, 虚析构)
                   /        \
            APIConfig       OllamaConfig
          (云端模型配置)   (本地Ollama配置)

              LLMProvider (纯虚基类 / 抽象接口)
                |     |        |           |
    ChatGPTProvider  DeepSeekProvider  GeminiProvider  OllamaLLMProvider
         (OpenAI)      (DeepSeek)     (Google)       (本地部署)


    LLMManager ---- 管理所有 Provider 实例 (map<name, unique_ptr>)
        |
    ChatSDK ---- 门面类，组合 LLMManager + SessionManager
        |
    SessionManager ---- 会话 CRUD，组合 DataManager
        |
    DataManager ---- SQLite 持久化层
```

### 2.2 核心设计模式

**1. Provider 模式（策略模式 + 工厂模式）:**
- `LLMProvider` 是纯虚基类，定义 6 个纯虚函数：`initModel()`, `isAvailable()`, `getModelName()`, `getModelDesc()`, `sendMessage()`, `sendMessageStream()`
- 每个具体 Provider（ChatGPT/DeepSeek/Gemini/Ollama）继承并实现这些接口，各自处理不同 API 的请求格式差异
- `LLMManager` 通过 `map<string, unique_ptr<LLMProvider>>` 统一管理所有注册的 Provider

**2. 门面模式（Facade）:**
- `ChatSDK` 是整个 SDK 的唯一对外入口，内部组合了 `LLMManager` 和 `SessionManager`
- 外部使用者只需调用 `ChatSDK::initModels()` → `createSession()` → `sendMessage()` 即可完成全部操作

**3. 配置多态（向下转型安全）:**
- `Config` 基类有虚析构函数（注释明确说明目的：确保 `dynamic_pointer_cast` 向下转型安全性）
- 通过 `shared_ptr<APIConfig>` 和 `shared_ptr<OllamaConfig>` 区分云模型和本地模型配置
- `ChatSDK::registerAllProvider()` 用 `dynamic_pointer_cast<OllamaConfig>` 判断配置类型

**4. 流式响应回调模式:**
- 所有 Provider 的 `sendMessageStream()` 接收一个 `std::function<void(const std::string&, bool)> callback`
- `bool` 参数表示是否为最后一个数据块，用于通知调用方流结束
- 服务端用 httplib 的 `content_receiver` + `set_chunked_content_provider` 实现 SSE 推送

**5. 双缓存策略（SessionManager）:**
- 内存中维护 `unordered_map<string, shared_ptr<Session>>` 用于快速查找
- SQLite 数据库做持久化存储
- 启动时从数据库恢复所有会话到内存；每次操作同步写数据库

#### 13. `sdk/src/ChatSDK.cpp` (328行)
**核心内容**: SDK 门面类的完整实现，是最核心的业务编排文件。

**关键流程**:

**a) `registerAllProvider()`** -- 固定注册 4 个 Provider:
1. deepseek-chat → `DeepSeekProvider`
2. gpt-4o-mini → `ChatGPTProvider`
3. gemini-2.0-flash → `GeminiProvider`
4. 遍历 configs，对 `OllamaConfig` 类型动态创建 `OllamaLLMProvider`

**b) `initProviders()`** -- 遍历 configs:
- `APIConfig` 类型 → 调用 `initAPIModelProviders()` (只支持 deepseek-chat/gpt-4o-mini/gemini-2.0-flash)
- `OllamaConfig` 类型 → 调用 `initOllamaModelProviders()`

**c) `sendMessage()` 全量发送流程**:
```
1. 检查 SDK 是否初始化
2. 通过 sessionId 获取 session 对象
3. 构造 user Message 并添加到 session
4. 从 session 获取历史消息列表
5. 从 _modelConfigs 取出 temperature/maxTokens 构建请求参数
6. 调用 _llmManager.sendMessage()
7. 构造 assistant Message 并保存到 session
8. 更新 session 时间戳
9. 返回完整回复
```

**d) `sendMessageStream()` 流式发送流程**: 与全量类似，但第 6 步改为调用 `sendMessageStream()` 并传入回调函数。

#### 22. `ChatServer/ChatServer.cpp` (452行)
**核心内容**: ChatServer 的完整实现，包含所有 API 路由处理逻辑。

**构造函数流程**:
1. 创建 `ChatSDK` 实例
2. 构建 4 个模型配置对象 (DeepSeek + ChatGPT + Gemini + Ollama)
3. 调用 `_chatSDK->initModels(modelConfigs)`
4. 创建 `httplib::Server` 实例

**start() 方法**:
- 设置 HTTP 路由规则
- 设置静态资源挂载点: `_chatServer->set_mount_point("/", "./www")`
- 在**独立线程**中启动 HTTP 监听（避免阻塞主线程）
- 使用 `serverThread.detach()` 分离线程

**7 个 API 路由**:

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/session` | 创建新会话 |
| GET | `/api/sessions` | 获取会话列表 |
| GET | `/api/models` | 获取可用模型 |
| DELETE | `/api/session/(.*)` | 删除指定会话 |
| GET | `/api/session/(.*)/history` | 获取历史消息 |
| POST | `/api/message` | 发送消息(全量) |
| POST | `/api/message/async` | 发送消息(流式/SSE) |

**流式响应实现 (`handleSendMessageStreamRequest`)**:
```cpp
response.set_chunked_content_provider("text/event-stream", [&](size_t offset, DataSink& dataSink)->bool{
    auto writeChunk = [&](const string& chunk, bool last){
        string sseData = "data: " + Json::valueToQuotedString(chunk.c_str()) + "\n\n";
        dataSink.write(sseData.c_str(), sseData.size());
        if(last){
            dataSink.write("data: [DONE]\n\n");
            dataSink.done();
            return false;
        }
        return true;
    };
    writeChunk("", false);  // 先发空包避免等待
    _chatSDK->sendMessageStream(sessionId, message, writeChunk);
    return false;
});
```

**关键点**: 使用 `Json::valueToQuotedString()` 对 chunk 做 JSON 编码，防止特殊字符破坏 SSE 格式。
